# PRODX Engineering Skills

The repository-standard production engineering skill set is:

1. `prodx-postgresql`
2. `prodx-financial-integrity`
3. `prodx-security`
4. `prodx-concurrency-idempotency`
5. `prodx-production-readiness`

These skills are operational checklists, not proof of implementation. Their evidence rules require executable tests, CI, database/integration evidence, or other direct proof before a capability can be marked PASS.

## Extended engineering coverage
The same framework also applies to the planned areas of offline/sync, distributed systems, observability, testing engineering, CI/CD, production infrastructure, and disaster recovery.

## Governance
Milestone completion remains subject to architecture, security, database, automated-test, independent-review, acceptance, merge, and post-merge verification gates defined by the PRODX Engineering Operating Model.
